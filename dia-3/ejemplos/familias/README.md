# Ejemplo · Catálogo de Familias

Los archivos completos del catálogo de Familias, por si te atoras al construirlo. Primero intenta hacerlo siguiendo el [paso a paso](../../paso-a-paso.md); si algo no te funciona, compara con estos.

| Archivo | Dónde va en tu proyecto |
|---|---|
| `Familia.cs` | `Modelos/` |
| `FamiliasDatos.cs` | `Datos/` |
| `FamiliasNegocio.cs` | `Negocio/` |
| `FamiliasHandler.ashx` y `FamiliasHandler.ashx.cs` | `Handlers/` |
| `Familias.aspx` | Raíz del proyecto (reemplaza el contenido de la tuya) |
| `familias.js` | `js/` |

Si copias los archivos en lugar de crearlos con *Agregar → Nuevo elemento*, inclúyelos en el proyecto: **Mostrar todos los archivos** → clic derecho → **Incluir en el proyecto**. Si no, Visual Studio no los compila.
